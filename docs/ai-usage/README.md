# AI の使い方の記録（Issue ごと）

提出ドキュメントの必須記入「AIをどの場面でどう使ったか，なぜその場面か」の材料．
1 つの Issue（PR）につき 1 ファイル `issue-<Issue番号>.md` を作り，気づいたときに表へ 1 行ずつ足す．

- PR どうしが同じファイルを触らないので衝突しない（#53）．`../ai-usage.md` の表は #53 より前の分で，以後は行を足さない
- Issue の無い作業（計画づくりなど）は `misc-<短い説明>.md` にする
- 提出書類を書くときは，`../ai-usage.md` の表とこのディレクトリのファイルを日付順に合わせて読む

ひな形（コピーして使う）:

```markdown
# AI の使い方（#N 短い題名）

| 日付 | 誰 | 場面 | どう使ったか | なぜその場面か／採用しなかったこと |
|---|---|---|---|---|
| 2026-11-08 | | 〇〇（#N） | Claude Code に〇〇を作らせ，〇〇は人が決めた | 〇〇するため．〇〇は採用しなかった |
```
