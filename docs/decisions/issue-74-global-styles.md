# 全体の見た目は素の CSS 1枚（index.css）と CSS 変数で決め，要素のセレクタを中心に効かせる（2026-11-08）

- 決めたこと:
  - `web/src/index.css` を `main.tsx` で読み，色・余白・角丸・文字の大きさを `:root` の CSS 変数にする．CSS フレームワーク・UI ライブラリ・Web フォントは使わない（文字は端末のフォント）
  - まず `button`・`input`・`textarea`・`fieldset`・`progress`・`[role="alert"]`・`[role="status"]` などの要素・属性のセレクタで効かせる．クラスは要素だけで決められない所（問題の詳細ページの区切り `.card`，思考ステップの一覧 `.step-list`，質問のスレッド `.thread`，AI の問いかけ `.ai-question`，薄い文字 `.muted` など）にだけ足す
  - 色: 分岐点の図の3色（`branchColors.ts` の青・橙・紫）は変えない．灰色は同じ系統（Tailwind の slate に当たる値）でそろえ，ボタン・リンク・フォーカスの色は3色のどれとも紛れない teal にした．質問のスレッドと AI の問いかけの線は灰色のままにし，道の色（だれの道か）と混ざらないようにした
  - AI の問いかけは細い灰色の線と薄い見出しのまま（強調しない）．「送信」系のボタン（`type="submit"`）だけを塗りつぶしで目立たせる
  - ヘッダー（タイトル・ログイン中の表示）を `<header>` に分け，本文は最大 52rem．スマホ幅（480px 以下）はカードの内側の余白を詰めて，分岐点の図の2列に幅を回す
- 理由:
  - Issue の指示（CSS フレームワークを入れない，素の CSS か CSS Modules）と，ほかの PR との衝突を減らすため．要素のセレクタなら各コンポーネントを触らずに全体が変わる
  - CSS Modules はコンポーネントごとに import と `className` の書き換えが要り，触るファイルが増えるので今回は使わなかった
  - 分岐点の色は「どちらの道か」の意味を持つので，ボタンに青や紫を使うと「左の道」「同じ区間」と取り違えるおそれがある
- 捨てた案とその理由:
  - 道の色を CSS 変数にして `branchColors.ts` と二重に持つ: 値がずれるおそれがあり，図以外で道の色を使う所が無いので，`branchColors.ts` だけに置いたままにした
  - ダークモード対応: 図の3色・カードの色をもう1組決めて確かめる手間に見合わないので，`color-scheme: light` にして今回は見送った
  - 開いている PR（#73・#56）が触っている `PostSection`・`StepsStatus`・`SubmitControls`・`PostView`・`OtherPost` の中のインラインの `style` は，衝突を避けるため触っていない（全体のスタイルは効く）
