# favicon は「分岐して合流する道」の形にする（2026-11-09）

- 決めたこと: favicon を，1本の道が分岐し（分岐点＝琥珀色），また1本に合流する（合流点＝薄いティール）形にする．地はアクセント色のティール `#0f766e` の角丸の四角
- 理由: プロダクトの根本は「複数人で1つの課題に取り組むときの思考プロセスを共有する」こと（思考版 GitHub）．別々に考え始め，分岐点で比べ，問い合って人がまとめる流れを1つの形で表せる．輪郭がまとまっているので 16px に縮めても形が読める
- 捨てた案とその理由:
  - 分岐するだけの Y 字: 分岐点は伝わるが，共有して一緒に進める部分が表せない
  - 3本に分かれる形: 複数人は伝わるが，合流しないので「ばらばらに考えて終わり」に見える
  - コミット履歴風に点を並べる形: GitHub らしさは強いが，点が多く小さくするとつぶれる
  - 2人の解法のはしご・向かい合う吹き出し・「ミ」の字・重なるノート: それぞれ「比べる」「問い合う」「名前」「手書き」の一部しか表せない．吹き出しはチャットアプリと見分けにくく，「ミ」は日本語が読めないと伝わらない
- 点の大きさ: 半径 11（道の太さ 8）．はじめは半径 8 で道と同じ太さだったので，16px では点がほとんど見えなかった（#96 のレビュー）．16px に描いて比べ，点が見えて道の輪の中もつぶれない 11 にした．12 にすると輪の中が狭くなる
- 琥珀色: 分岐点の図（`web/src/branchColors.ts`）では右の人の道の色．アイコンでは分岐点の印に使う．#95 で決めた配色のままにする．デモでアイコンの色を説明するときは，図の色と取り違えられないよう気をつける
- 注意: 合流点は「AI がまとめた答え」ではなく「人が比べて決めたところ」と説明する（AI は正誤を判定しない原則）．Git のロゴに似せないよう，色はティールのままにし，四角は傾けない
