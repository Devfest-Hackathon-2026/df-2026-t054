# ミチクラベ

DevFest GDGoC Japan Hackathon 2026 / 教育カテゴリ

**「答え」ではなく「なぜそう考えたか」を持ち寄り，比べ，問い合う学習プラットフォーム**

- デプロイ URL: https://gdgoc-hackathon-513704.web.app （Google アカウントでログインして使う）

## 何をするものか

同じ問題を別々に解いた学生どうしで，解き方を「思考ステップ」に分けて並べ，**どこで考え方が分かれ，どこで合流したか**を見て，問いを出し合う場所です．対象は，輪読会・自主ゼミで一緒に問題を解く理系の大学生です．

模範解答とは比べません．AI は答えや理由を代わりに書かず，正しいかどうかも判定しません．AI がするのは **整理する・比べる・問いかける** ことだけで，判断と説明は人がします．

## 使い方

1. **問題を作り，招待リンクで仲間を呼ぶ**
2. **それぞれが自分の解き方を投稿する**: 手書きの写真・LaTeX・短い説明動画のどれか．**全員が提出するまで，ほかの人の投稿は見えない**（先に見て引きずられないため）
3. **思考ステップになる**: Gemini が投稿を「何をしたか」「なぜそうしたか」「元の場所（写真の範囲・動画の時刻）」をもつステップの列に分ける．自分の動画の投稿では，ステップの時刻を押すとその場面から再生できる
4. **分かれ道の図で比べる**: 2人のステップを AI が対応づけ，「分岐点」「合流点」を図に出す（3人以上なら比べる2人を選ぶ）
5. **問う**: 分岐点と「なぜ」が空のステップに AI が問いかけ，本人が理由を書き込む．ほかの参加者もステップに質問を付け，返信で話し合える
6. **式変形を確かめる（参考）**: AI が写した式を SymPy で計算した結果を参考に出す．正しいかどうかは人が確かめる

## Google 技術とその使い方

| 機能 | 使っている技術 |
|---|---|
| 写真・LaTeX・動画を思考ステップに分ける | Gemini（Vertex AI）の画像・動画の理解と構造化出力．動画は映像と音声をまとめて理解し，ステップを時刻に結び付ける |
| 2つの解き方の対応づけ（分岐点・合流点） | Gemini の構造化出力．AI が答えるのは「同じことをしたステップの組」だけで，区間に並べるのはコード |
| 分岐点での問いかけ | Gemini．問いの形になっていないもの・理由や評価を含むものはコードで捨て，決まった文に置き換える |
| 式変形の確認 | Gemini のコード実行で，こちらが組み立てた SymPy のコードを動かす |
| 全員が提出するまで非公開・締め切り | Firestore と Cloud Storage for Firebase のセキュリティルール |
| 投稿をきっかけにした処理 | Cloud Functions for Firebase（2nd gen，Cloud Run 上で動く） |
| ログイン・配信 | Firebase Authentication（Google ログイン），Firebase Hosting |

## ディレクトリ

| パス | 中身 |
|---|---|
| `web/` | フロントエンド（Vite + React + TypeScript）．Firebase Hosting に配信 |
| `server/` | 投稿を思考ステップにする・対応づける・問いかける・式を確かめる Cloud Functions |
| `shared/schema/` | 思考ステップ・対応関係・問いかけ・式の確認の JSON スキーマ |
| `firebase/` | Firestore・Storage のセキュリティルールとそのテスト |
| `poc/` | 作る前に Gemini の動画・画像の扱いを確かめた PoC |
| `docs/decisions/` | 技術選定・設計の判断の記録（選んだ理由と捨てた案） |
| `docs/ai-usage/` | 開発で AI（Claude Code）をどう使ったかの記録 |
| `docs/licenses.md` | 使った依存ライブラリ・素材・データの一覧 |

## 手元で動かす

Node.js と，Firebase のプロジェクトが要ります．環境変数の名前は `web/.env.example`・`server/.env.example` にあります（`cp .env.example .env` して値を書く）．

```bash
cd web
npm install
npm run dev
```

ルールのテスト（エミュレータを立てて流す．Java が要る）:

```bash
cd firebase
npm install
npm test
```
